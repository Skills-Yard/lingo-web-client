# Lingo web client

Next.js 16 (App Router), React 19, Tailwind v4. Check types and lint with `npx tsc --noEmit` and
`npx eslint <paths>`; there is no test runner.

## 3D character page (`/character`, branch `feat/3d`)

Read `src/components/character3d/CONTEXT.md` first. It has what the page does, the files, the
non-obvious gotchas (bone names, retargeting, the Next image optimizer, the dev cache), what was
not verified, and the open items. Run it with `npm run dev` and open `/character`.

## How to work with this user

- They write Hinglish (Hindi in Roman script): answer in the same, short. They are often in a hurry.
- Ask before installing any package: name it and wait for a yes.
- Do not commit or push unless asked.
- Say plainly what was and was not checked (for example, headless Chrome only, not a real phone).
